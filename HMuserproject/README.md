# 验证码登录演示（HMuserproject）

基于 **Flask** 的验证码登录示例项目，流程与鸿蒙课程对接端一致。演示了"获取图形验证码 → 校验图形验证码 → 发送短信验证码 → 手机号+短信验证码登录 → 保存用户信息"的完整链路。

## 项目简介

模拟业务平台的用户登录流程，包含：

- 图形验证码生成与校验（Pillow 绘制）
- 短信验证码发送与校验（模拟实现，含 5 分钟有效期）
- 手机号 + 短信验证码登录
- 用户信息存储（JSON 文件）与会话管理
- 内置演示账号（`120666666673`）

## 目录结构

```
HMuserproject/
└── userProject/
    ├── app.py               # Flask 主程序
    ├── requirements.txt     # 依赖清单
    ├── API.md               # 接口文档
    ├── README.md            # 原项目说明（鸿蒙课程对接版）
    ├── users.json           # 用户数据（运行时自动生成）
    ├── templates/
    │   └── index.html       # 前端页面
    └── static/
        └── cat.jpg          # 静态资源（头像）
```

## 运行方式

```bash
pip install -r requirements.txt
python app.py
```

启动后浏览器访问 `http://127.0.0.1:5000` 即可体验登录流程。

## 接口概览

完整接口见 `userProject/API.md`，主要包括：

| 接口 | 说明 |
| --- | --- |
| 获取图形验证码 | 返回验证码图片，服务端暂存用于校验 |
| 校验图形验证码 | 提交图形验证码进行校验 |
| 发送短信验证码 | 向手机号发送验证码（模拟） |
| 手机号短信登录 | 校验短信验证码并登录 |

## 备注

- `app.py` 中的 `secret_key`、演示账号密码均为开发用默认值，部署前需修改。
- 图形验证码 / 短信验证码存储于内存（`CODE_STORE`），服务重启即失效。
